## 🌟 Overview

This is the source code for my personal developer portfolio, built with clean semantic HTML5, modern CSS3, and vanilla JavaScript. It is designed around accessibility, performance, and clear storytelling.

### 🚀 Key Features

- **Empathetic Storytelling:** Highlights my journey discovering patterns in data and engineering thoughtful tools for everyday community challenges.
- **Flagship Project Deep Dive:** Full breakdown of **Where Can I Sit?**, explaining why accessibility features like shade, backrests, armrests, and step-free access matter before heading out.
- **Interactive K-Means Clustering Visualizer:** An in-browser 2D unsupervised machine learning playground that calculates Euclidean distances and moves cluster centroids in real-time.
- **Dynamic Projects Grid:** Filterable showcase displaying working prototypes:
  - 🪑 *Where Can I Sit?* (Community Seating & Accessibility Map)
  - 🌀 *CyScan AI* (Deep Learning Satellite Cyclone Detection Concept)
  - 🌿 *FloraPulse* (Botanical Encyclopedia & Adaptive Watering Calculator)
- **What I'm Learning:** Grounded reflections on machine learning fundamentals, data visualization, and accessible web standards.
- **Theme Switcher:** Seamless transition between Midnight Dark mode and Crisp Light mode with persistent state.
- **Mobile Responsive:** Fluid layout optimized for all viewport sizes.

## 🛠️ How to Run Locally

You can open `index.html` directly in any modern web browser:

1. Clone or download this repository.
2. Double-click `index.html` (or use Live Server in VS Code).
3. To test the K-Means Playground, select your preferred number of clusters ($K$) and click **Step Algorithm**!

---

## 🌐 Deploying to GitHub Pages (1-Click)

1. Push this folder to a GitHub repository named `portfolio` (or `your-username.github.io`).
2. Go to **Settings** > **Pages** in your GitHub repository.
3. Under **Branch**, select `main` and `/ (root)`.
4. Click **Save**. Your portfolio will be live at `https://your-username.github.io/`!
